# NexoProject-V2 - Revisión de Proyecto

## Visión General
NexoProject-V2 es un proyecto modular compuesto por múltiples subproyectos/plugins para un ecosistema. Está gestionado por Gradle (Kotlin DSL).

## Módulos Identificados

* **NexoCore**: El núcleo central del proyecto.
* **NexoItems**: Sistema de ítems personalizados o gestión de ítems.
* **NexoPvP**: Funcionalidades relacionadas con Player vs Player (Combate).
* **NexoProtections**: Sistema de protección de zonas/bloques.
* **NexoMinions**: Sistema de entidades automatizadas (Minions).
* **NexoMechanics**: Mecánicas generales del servidor/juego.
* **NexoFactories**: Sistema de fábricas/producción.
* **NexoEconomy**: Sistema económico.
* **NexoDungeons**: Sistema de mazmorras/eventos PvE.
* **NexoColecciones**: Sistema de coleccionables o almacenamiento de objetos.
* **NexoClans**: Sistema de clanes/guilds.
* **NexoWar**: Guerras, probablemente conectado con NexoClans.
* **NexoChat**: Sistema de gestión de chat, formatos y canales.
* **NexoIslas**: Sistema tipo Skyblock o islas flotantes.
* **NexoTools**: Herramientas utilitarias (probablemente herramientas administrativas).
* **NexoCrates**: Sistema de cajas de recompensas (lootboxes).
* **NexoCosmetics**: Sistema de cosméticos para los jugadores (incluyendo el sistema de Boombox detectado previamente).
